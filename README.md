Scenario: A company has set up a remote office that requires access to the data center for file sharing, internal applications, and web services. The remote office connects via a leased line (MPLS or dedicated line) and requires secure, efficient communication. 

Requirements: 

● Configure static and dynamic routing between the data center and the remote office.

● Implement EIGRP or OSPF for automatic route distribution and redundancy.

● SetupACLstoallow traffic only for specific services (e.g., block non-essential ports such as FTP while allowing HTTPS).

● Create route filters and route maps to control route advertisement between the remote office and the data center to optimize routing paths and reduce unnecessary traffic
